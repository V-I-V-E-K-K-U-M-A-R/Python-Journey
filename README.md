# Python-Journey

![Python](https://img.shields.io/badge/Python-3.x-blue.svg)

A repository to document my learning journey with Python, focusing on data structures and algorithms in preparation for LeetCode challenges.

## About This Project

This project serves as a personal knowledge base. Each folder is dedicated to a specific Python topic, containing well-commented code examples that demonstrate key concepts and usage. The goal is to create a thorough and practical reference guide for myself and anyone else looking to solidify their Python fundamentals.

## Topics Covered

As this journey progresses, this section will list all the topics documented in this repository.

*   **[Dictionaries](./Dictionary/)**: Exploring Python's `dict` type, including creation, access, iteration, and common methods.
*   **[Syntax](./Syntax/)**: Covering Python's basic syntax, including `print()`, `input()`, loops, and statements.
*   *(More topics to be added...)*

## How to Use

Each folder contains Python scripts that can be executed directly to see the concepts in action.

For example, to run the dictionary examples:

```bash
cd Dictionary
python dictionary.py
```
